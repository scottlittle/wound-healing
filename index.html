How to Use

Run the phases in order:

  1. Intention Phase (1st): For each run, apply your energy healing during the 10-second countdown. Expect ~10 runs per minute.
  2. Run Analysis (2nd): Click "Run Analysis" after the intention phase completes. This automatically runs the control phase in the background and then displays the comparison results instantly.

Estimated times (50 runs):
Intention phase: ~5 minutes
Analysis (includes control phase): ~5 seconds

Random Seeds: On page load, random seeds are fetched automatically. This takes a few seconds because it first attempts to get quantum random seeds from the ANU Quantum Random Number Generator. If that service is unavailable, it falls back to system random seeds.
